# Chaos — 12x12, offense-only, advance=8

> Only mobile/chaotic patterns allowed. advance=8 means gliders move 2 cells per turn. Hypothesis: high-action spaceship warfare. Will it be exhilarating or unreadable?

## Setup

- **Grid:** 12 × 12
- **Palette:** GliderSE, GliderSW, GliderNE, GliderNW, RPent
- **Advance steps per turn:** 8
- **Rules:** Same grid as baseline but advance=8 and offense-only palette

### Design questions this scenario tests

- Does advance=8 feel fast-exciting or too-fast-uncontrollable?
- Are only-spaceships too unstable for strategic play?
- Is the R-pentomino a useful tool or pure randomness?
