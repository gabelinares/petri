# Puzzle 03 — Glider Strike

> SOLO PUZZLE. A stable Block sits in the center of the dish. Goal: destroy it in ≤ 2 moves using a Glider. Teaches spaceship travel + deliberate collision targeting.

## Setup

- **Grid:** 10 × 10
- **Palette:** GliderSE, GliderSW, GliderNE, GliderNW
- **Advance steps per turn:** 4
- **Rules:** Solo mode. Prompt: 'Destroy the specimen in 2 moves.' Win check: block cells (original X cells) all gone at end.

### Design questions this scenario tests

- Does a glider hitting a block from NW actually destroy it?
- Is 2 moves the right budget (too easy / too hard)?
- Can the player aim the glider correctly with ghost preview?
