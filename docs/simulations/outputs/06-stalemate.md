# Stalemate — 12x12, defense-only

> Only still-life patterns allowed. Hypothesis: both players plant immortal territory and nothing ever dies. The math: whoever places more cells wins, which collapses to pure placement counting. Boring?

## Setup

- **Grid:** 12 × 12
- **Palette:** Block, Beehive, Boat, Tub
- **Advance steps per turn:** 4
- **Rules:** Same as baseline but defense-only palette

### Design questions this scenario tests

- Does a pure-defense game just become 'who places more cells'?
- Is there ANY strategic decision when nothing moves?
- Do adjacent still lifes break (as we saw in scenario 01)?

- `.` dead (empty agar)
